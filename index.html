To safeguard retail and hospitality clients from operational disruptions, recurring renewal commissions are subject to active service terms:

• Active Support Obligation: Annual renewal share requires the partner to actively deliver primary operational check-ins and basic configuration resolution.
• Support Abandonment: If a reseller discontinues customer support, recurring renewal commissions pause or transfer to the re-assigned servicing agent.
• Client Reassignment: If a client formally requests migration to an alternate certified partner due to non-support, recurring credits transfer to the newly assigned steward.
• Account Ownership: Sentama Technologies does not directly poach clients introduced and actively serviced by an accredited partner.

                     Web App Manifest (manifest.json)
                    
                  

                  
Contains `standalone` display mode, valid 192px/512px icons, theme colors, and start_url for home screen installs.

                

                

                  

                     Local Client Database (IndexedDB)
                    
                  

                  
Stores active offline vouchers, items, and transactions locally on device storage without depending on live network APIs.

                

                

                  

                     Background Asynchronous Sync
                    
                  

                  
Queues background tasks using the Background Sync API to push vouchers when connection recovers without user intervention.
